# Israel Coders — לומדים פייתון ביער הקוד

אתר ללימוד פייתון בעברית: שיעורים, משימות עם בדיקה אוטומטית, ועוזר AI (ינשוף) שעוזר לחשוב — בלי לגלות את התשובה.

## הפעלה (פעם ראשונה)

1. התקינו **Python 3.10 ומעלה** מ-python.org (בהתקנה ב-Windows סמנו "Add Python to PATH").
2. פתחו טרמינל בתיקיית הפרויקט והריצו:
   ```
   python server.py
   ```
3. פתחו בדפדפן: **http://localhost:8123**

אין צורך להתקין שום ספרייה — הכל עובד עם פייתון הרגיל.

## הגדרות — קובץ `.env`

| הגדרה | מה זה |
|---|---|
| `NVIDIA_API_KEY` | המפתח של ינשוף (העוזר). בלי מפתח ינשוף עובד במצב רמזים מוכנים |
| `NVIDIA_MODEL` | מודל ה-AI |
| `TEACHER_CODE` | הקוד שמורים מקלידים בהרשמה. שתפו רק עם מורים |

**חשוב:** אל תעלו את `.env` לאינטרנט או ל-GitHub (קובץ `.gitignore` כבר דואג לזה).

## מה יש בפרויקט

| קובץ | תפקיד |
|---|---|
| `server.py` | השרת: כניסה וחשבונות, שמירת התקדמות, כיתות, ינשוף, אבטחה |
| `index.html`, `app.js`, `styles.css` | האפליקציה עצמה |
| `exercises.js` | כל המשימות והטסטים |
| `lessons.js` | השיעורים והשאלות "מה יודפס?" |
| `glossary.js` | מילון: מה כל מילה בפייתון עושה |
| `explain.js` | הסבר צעד אחר צעד |
| `solutions.json` | פתרונות לדוגמה (נשלחים רק אחרי שפותרים) |
| `login.*` | דף הכניסה וההרשמה |
| `teacher.*` | לוח המורה |
| `images/` | רקע, ינשוף ותגים |
| `DEPLOY.md` | איך מעלים את האתר לאינטרנט |

## קבצי נתונים (נוצרים לבד)

`users.json` (חשבונות, סיסמאות מוצפנות), `progress.json` (התקדמות), `classes.json` (כיתות), `sessions.json` (חיבורים), `.secret_key`.
כדאי לגבות את `users.json`, `progress.json` ו-`classes.json`. אם מוחקים אותם — מתחילים מאפס.
