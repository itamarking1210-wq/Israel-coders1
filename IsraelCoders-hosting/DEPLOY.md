# העלאת Israel Coders לאינטרנט

## חשוב לדעת קודם

האתר צריך **שרת פייתון** (קובץ `server.py`) — בשבילו יש כניסה, שמירת התקדמות, כיתות וינשוף.
לכן הוא **לא יעבוד** באחסון של "אתר סטטי" בלבד (GitHub Pages, Netlify Drop, אחסון HTML רגיל).
צריך שירות שמריץ פייתון, למשל **Render**, **Railway** או **Fly.io**.

השרת מזהה לבד שהוא רץ אצל שירות אחסון ומגדיר את עצמו: מקשיב לאינטרנט, מקבל את הכתובת של האתר,
ועובר ל-HTTPS מאובטח. לא צריך לשנות קוד.

## הדרך המומלצת: Render (יש תוכנית חינם)

1. פתחו חשבון ב-GitHub וצרו מאגר (Repository) חדש.
2. העלו אליו את **כל הקבצים מתוך `IsraelCoders-hosting.zip`** (חלצו קודם, וגררו את הקבצים לדף של המאגר).
3. פתחו חשבון ב-render.com ← **New +** ← **Web Service** ← חברו את המאגר.
4. הגדרות:
   - **Runtime:** Python
   - **Build Command:** `echo no build needed`
   - **Start Command:** `python server.py`
5. תחת **Environment** הוסיפו:
   - `NVIDIA_API_KEY` — המפתח של ינשוף
   - `TEACHER_CODE` — קוד המורים (תמציאו אחד, למשל `TEACH-` ועוד 8 תווים)
6. **Create Web Service**. אחרי דקה-שתיים תקבלו כתובת כמו `https://israel-coders.onrender.com` — וזה האתר.

(יש גם קובץ `render.yaml` מוכן: ב-Render בוחרים **New + ← Blueprint** והוא ממלא את רוב ההגדרות לבד.)

### שימו לב: שמירת נתונים
בתוכנית החינמית של Render, הקבצים נמחקים בכל עדכון או הפעלה מחדש — כלומר **החשבונות וההתקדמות יימחקו**.
כדי לשמור אותם צריך **Disk** (בתשלום): מחברים דיסק בנתיב `/data`, ומוסיפים משתנה סביבה `DATA_DIR=/data`.

## Railway / Fly.io / אחרים
יש בפרויקט `Procfile`, `requirements.txt` ו-`Dockerfile` — רוב השירותים מזהים אותם לבד.
מגדירים את אותם משתני סביבה (`NVIDIA_API_KEY`, `TEACHER_CODE`), ולשמירת נתונים מחברים Volume ו-`DATA_DIR`.

## מהמחשב שלכם, עם Cloudflare Tunnel (להדגמה מהירה)
1. הריצו `python server.py`
2. בחלון נוסף: `cloudflared tunnel --url http://localhost:8123`
3. הוסיפו ל-`.env` את הכתובת שקיבלתם: `PUBLIC_URL=https://....trycloudflare.com` והפעילו מחדש את השרת.

## הגדרות מתקדמות (לא חובה)

| משתנה | מה הוא עושה |
|---|---|
| `PUBLIC_URL` | הכתובת של האתר. ברוב השירותים מזוהה לבד |
| `DATA_DIR` | תיקייה לשמירת משתמשים, התקדמות וכיתות |
| `HOSTED=1` | מכריח מצב "אינטרנט" בשירות שלא זוהה אוטומטית |
| `HOST`, `PORT` | כתובת ופורט להאזנה (השירות בדרך כלל מגדיר לבד) |
